# StockMaster · Control de inventario (React + Tailwind)

    npm install
    npm run dev

- CRUD de productos (agregar, listar, editar, eliminar) con validación, búsqueda y filtro por stock.
- Salidas de inventario: descuentan stock; anularlas lo devuelve. Exportación a CSV.
- Persistencia en localStorage mediante `src/services/api.js` (API simulada con latencia).
  Para usar un backend real, reemplaza solo ese archivo.
